Agent X-84 & $KABOOM

Agent X-84 is a collection of up to 1,200 alien collectibles on Base, connected to the $KABOOM token. The public drop lets users mint the next available token ID with $KABOOM.

How the ecosystem works

The initial mint price is 500,000 $KABOOM and can be changed by the NFT owner. The mint payment goes to Development & Operations. Separately, the funded ecosystem budget burns 50,000 tokens and pays 50,000 tokens to the minter for each successful mint. NFT transfers do not repeat these payments.

What is ready

The token and NFT contracts are deployed. Local artwork and metadata have been prepared. Public metadata hosting and marketplace display still need verification before the drop is announced as ready. Plans and community activity are not promises of financial returns.
